# Found Fluency – published site

Live: https://www.foundfluency.com/

This branch holds the **built** website. The source is the Lovable project
(repository `fluency-foundry-coaching`); it is prerendered with
`vite build --config vite.static.config.ts` and copied here for GitHub Pages.
Do not edit these files by hand – change the Lovable project and publish again.

The previous hand-written site is kept in the `old-site` branch.
